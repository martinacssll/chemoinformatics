## MOOC assignments

Open and run on Google Colab, having the generators data folder in Google Drive:
1. QSAR_model.ipynb : data curation and QSAR model training and prediction of de novo dataset
2. chemical_space_visualization.ipynb : PCA and tSNE on reference and de novo datasets (requires output from notebook 1)
3. scoring_generated_molecules.ipynb : score de novo molecules (requires output from notebook 1)
